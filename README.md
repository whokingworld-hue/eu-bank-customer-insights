Analyzing customer churn patterns across European banking segments to identify high-risk groups and drive targeted retention strategies.

## 📊 Key Features
- **Geographic Analysis**: Churn rates by country (France, Spain, Germany)
- **Demographic Insights**: Age, gender, and tenure-based churn trends
- **Financial Segmentation**: Credit score vs. balance risk analysis
- **High-Value Customer Focus**: Patterns for premium account holders
- **Interactive Dashboards**: Drill-down into segments with dynamic filters
